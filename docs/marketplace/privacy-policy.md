# Privacy policy

Desk Calculator evaluates expressions in the browser. Calculator expressions and results are not sent to an external service by this app.

The app stores the position of the floating calculator icon in the browser's local storage so it can be restored on later visits. Clearing browser storage removes that saved position. Frappe Cloud or the site operator may independently collect the technical data described in their own privacy policies.

For privacy questions, contact [amalageorge.work@gmail.com](mailto:amalageorge.work@gmail.com).
